# ViewGenerator Lab

A controlled browser playback simulator for a school/research experiment.

## Safety boundary
The app locks the case-study URL to a specific TikTok video, but playback is performed against a local/demo video. It does not automate TikTok, manufacture platform views, or manipulate engagement metrics.

## Run
npm install
npm run dev

## Production
npm run build

The app stores only local simulator records in browser localStorage.
